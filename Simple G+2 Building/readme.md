A regular reinforced-concrete frame used to practise the complete ETABS gravity-analysis workflow: grids, materials, sections, supports, load calculation, load assignment and load combinations.

**Status:** ✅ Model built and analytical model checked. Gravity loading only (no lateral loads). See [Review notes](#review-notes).

## Model

| Item | Value (from `Final/Simple G+2 Building.e2k`) |
|---|---|
| Software | ETABS 23.2 |
| Grid | 3 × 4 bays at 4.0 m (12 m × 16 m), 20 columns |
| Storeys | Base → Story1 (2.0 m) → Story2, Story3, Story4 (3.0 m each) |
| Concrete | M25 |
| Reinforcement | HYSD415 |
| Beams | B250 × 300 mm |
| Columns | C300 × 300 mm |
| Slabs | 150 mm thin shell |
| Supports | Fixed at all column bases |
| Design preference | BS 8110-97 |

## Loads

**Wall load** (brick masonry, γ = 19 kN/m³, 240 mm thick, 3.0 m high):

```
w = 19 × 0.24 × 3.0 = 13.7 ≈ 14 kN/m   (applied to all beams)
```

| Load | Value |
|---|---|
| Self-weight | Generated by ETABS |
| Floor finish (SDL) | 1.5 kN/m² |
| Live load | 2.0 kN/m² |
| Wall load | 14 kN/m on beams |

**Load combination:** 1.4DL + 1.6LL (BS 8110 ultimate limit state).

## Review notes

- In the exported model, the combination `1.4DL+1.6LL` contains **Dead × 1.4 and Dead × 1.6**; the second factor should be applied to **Live**.
- The C300x300 section is defined as 300 × 250 mm in the model.
- The 14 kN/m wall load is also applied to the roof beams, where a parapet load would be more realistic.
- Next steps: add the lateral (wind/seismic) loads, run the concrete frame design and record the reinforcement results.
