# Final File: ETABS Text Export

`G+1 Commerial_Building.e2k` is the plain-text export of the final ETABS model of the [G+1 Commercial Building](..). It can be read in any text editor or on GitHub without ETABS, and imported back into ETABS (File → Import → ETABS .e2k).

It contains the complete model definition: storeys, materials (M25, HYSD500), frame and slab sections, geometry, supports, load patterns (dead, live, wall, floor finish, staircase, lift and tank, IS 1893 seismic, IS 875 wind), mass source, load combinations and IS 456 design preferences.

Saved from ETABS 23.2 on 6 Jul 2026.
